# 实时股票监控系统

仿Word文档样式的实时股票监控网页，支持A股、港股实时行情监控。

## 功能特性

✅ **仿Word文档样式** - 白色A4纸效果，专业美观  
✅ **实时行情监控** - 每3秒自动更新股价数据  
✅ **支持A股+港股** - 沪市(sh)、深市(sz)、港股(hk)  
✅ **自定义监控列表** - 自由添加/删除监控标的  
✅ **数据持久化** - 使用LocalStorage保存监控列表  
✅ **红涨绿跌** - 符合中国股市配色习惯  

## 技术架构

### 前端
- 纯HTML + CSS + JavaScript
- 仿Word文档样式
- LocalStorage数据存储

### 后端
- Node.js + Express
- 代理腾讯财经接口(qt.gtimg.cn)
- 解决CORS跨域问题
- GBK编码转换

## 使用方法

### 添加股票

在输入框中输入股票代码，格式如下：
- **沪市A股**：`sh600519` (贵州茅台)
- **深市A股**：`sz000001` (平安银行)
- **港股**：`hk00700` (腾讯控股)

输入后点击"添加"按钮或按Enter键

### 查看实时行情

添加股票后，表格将自动显示：
- 股票名称
- 当前价格
- 涨跌额
- 涨跌幅
- 成交量
- 换手率

数据每3秒自动更新一次

### 删除股票

点击每行的"删除"按钮可移除监控标的

## 数据源

**腾讯财经接口** (`qt.gtimg.cn`)
- ✅ 完全免费
- ✅ 无需注册
- ✅ 实时行情
- ✅ 支持A股、港股、美股
- ⚠️ 非官方接口，稳定性无保障

## 注意事项

1. **非交易时段**：非交易时间（盘前、盘后、周末）返回的数据可能不是最新行情
2. **接口稳定性**：腾讯财经接口为非官方接口，可能随时变更或失效
3. **请求频率**：建议不要过于频繁请求，避免被封IP
4. **商业使用**：如需商业使用，建议购买官方数据接口

## 常见问题

**Q: 为什么需要后端服务器？**  
A: 因为腾讯财经接口不支持CORS跨域请求，需要通过后端代理来绕过浏览器限制。

**Q: 可以不用后端吗？**  
A: 可以，但需要使用CORS代理服务（如cors-anywhere），但稳定性和安全性较差，不推荐生产环境使用。

**Q: 数据延迟多少？**  
A: 腾讯接口提供的是实时行情，延迟通常在1-3秒左右。

**Q: 支持多少只股票同时监控？**  
A: 理论上无限制，但建议不超过50只，避免请求过于频繁。
